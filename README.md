# Club del Editor

Landing para vender cursos de edición. Next.js + Vercel.

## Personalizar

En `src/app/page.tsx`:

- `BRAND`
- `WHATSAPP` (código de país, sin `+`)
- `INSTAGRAM` (sin `@`)

## Local

```bash
npm install
npm run dev
```

Sitio en producción: https://club-cueros.vercel.app
